# WeMath PDF previews

**Preview only. Never merge this branch.** These PDFs are built in the cloud with stand-in fonts (Inter and Liberation Sans instead of Avenir and Arial Rounded), so the lettering looks a little different from the real ones. The layouts, problems and answers are the same.

Use this branch to look at new packets on GitHub before building them on the Mac. The real PDFs come from running `python build_worksheets.py` on the Mac on the working branch.

Each folder has `color/` and `black-and-white/`, with the packet, the answer key and the check-in. Assessments are in `assessments/`.

New in this round: grade 6, third round. Packets 101–105: area of triangles and other shapes, volume with fractions, surface area and nets, mean/median/mode, data displays, with Check-Ins, and the grade 6 assessments now cover packets 91–105. Box plots are left out (they need a number line).
